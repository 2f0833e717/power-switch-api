# 起動方法

このアプリの起動方法をまとめています。用途に応じて最適な方法を選択してください。

## 起動方法一覧

| 方法 | 用途 | 必要なもの | 推奨度 |
|------|------|-----------|--------|
| [バッチファイル](#方法1-バッチファイルで起動推奨) | 日常使用 | Node.js | ⭐⭐⭐ |
| [PowerShellスクリプト](#方法2-powershellスクリプトで起動) | 日常使用 | Node.js, PowerShell | ⭐⭐ |
| [npmコマンド](#方法3-npmコマンドで起動開発用) | 開発用 | Node.js | ⭐⭐ |
| [.exeファイル](#方法4-exeファイルで起動配布用) | 配布・Node.js不要 | なし | ⭐⭐⭐ |
| [ターミナルから直接実行](#方法5-ターミナルから直接実行) | 開発・デバッグ用 | Node.js | ⭐ |

## 方法1: バッチファイルで起動（推奨）

**最も簡単で推奨される方法です。**

### 手順

1. `start.bat` をダブルクリック
2. 自動的に依存関係がインストールされ、サーバーが起動します

### 特徴

- ✅ ダブルクリックで起動できる
- ✅ 依存関係の自動インストール
- ✅ 既存プロセスの自動停止
- ✅ `.env`ファイルの存在確認
- ✅ エラーメッセージが分かりやすい
- ✅ 起動後に自動でブラウザが開く

### 起動後の確認

サーバー起動後、自動でブラウザが `http://localhost:3000` を開きます。

ブラウザが自動で開かない場合は、手動で `http://localhost:3000` にアクセスしてください。

### 停止方法

起動したコンソールウィンドウを閉じるか、`Ctrl+C` を押してください。

---

## 方法2: PowerShellスクリプトで起動

PowerShellを使用する場合の起動方法です。

### 手順

1. PowerShellを開く
2. プロジェクトディレクトリに移動
3. 以下のコマンドを実行：

```powershell
.\start.ps1
```

### 特徴

- ✅ バッチファイルと同様の機能
- ✅ PowerShellの豊富な機能を活用
- ✅ より詳細なエラーハンドリング
- ✅ 起動後に自動でブラウザが開く

### 注意事項

初回実行時、PowerShellの実行ポリシーエラーが発生する場合があります：

```powershell
# 実行ポリシーを設定（管理者権限で実行）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 方法3: npmコマンドで起動（開発用）

開発者向けの起動方法です。

### 手順

```bash
npm start
```

または

```bash
npm run dev
```

### 特徴

- ✅ シンプルで直接的な起動方法
- ✅ 開発中に便利
- ✅ 起動後に自動でブラウザが開く
- ⚠️ 依存関係がインストールされている必要がある
- ⚠️ 既存プロセスの停止は手動で行う必要がある

### 事前準備

```bash
# 依存関係のインストール（初回のみ）
npm install
```

## 方法4: .exeファイルで起動（配布用）

Node.jsがインストールされていない環境でも動作する方法です。

### 前提条件

`.exe`ファイルをビルドする必要があります。詳細は [BUILD.md](./BUILD.md) を参照してください。

### ビルド手順

```bash
npm run build:nexe
```

### 起動手順

1. `dist` フォルダ内の `switchbot-app-nexe.exe` をダブルクリック
2. または、コマンドプロンプトから実行：

```cmd
dist\switchbot-app-nexe.exe
```

### 初回設定

**重要**: `.exe`ファイルを実行する前に、`.exe`ファイルと同じディレクトリ（`dist`フォルダ）に`.env`ファイルを配置してください。

1. `dist`フォルダに`.env`ファイルを作成（またはコピー）
2. `.env`ファイルに認証情報を設定
3. （Windowsのみ）`minimize_browser_window.ps1`を`dist`フォルダに配置（ブラウザ最小化機能を使用する場合）

詳細は [SETUP.md](./SETUP.md) を参照してください。

### 特徴

- ✅ Node.jsがインストールされていない環境でも動作
- ✅ 単一のexeファイルで完結
- ✅ 配布が簡単
- ✅ 起動後に自動でブラウザが開く
- ✅ タイムアウト機能（デフォルト10秒後に自動終了）
- ✅ ブラウザウィンドウの自動最小化（Windows）
- ⚠️ ビルドに時間がかかる（初回は数分）
- ⚠️ `.env`ファイルを`dist`フォルダに配置する必要がある
- ⚠️ `minimize_browser_window.ps1`を`dist`フォルダに配置する必要がある（Windows）

### 停止方法

起動したコンソールウィンドウを閉じるか、`Ctrl+C` を押してください。

エラーが発生した場合、コンソールにエラーメッセージが表示されます。キー入力まで待機してメッセージを確認してください。

## 方法5: ターミナルから直接実行

開発・デバッグ用の起動方法です。

### 手順

#### Windows (コマンドプロンプト)

```cmd
node server.js
```

#### Windows (PowerShell)

```powershell
node server.js
```

#### 環境変数を設定して実行

```cmd
# コマンドプロンプト
set DEBUG=1
node server.js
```

```powershell
# PowerShell
$env:DEBUG=1
node server.js
```

### 特徴

- ✅ 最も直接的な起動方法
- ✅ デバッグ時に便利
- ✅ 環境変数を簡単に設定できる
- ✅ 起動後に自動でブラウザが開く
- ⚠️ 依存関係がインストールされている必要がある
- ⚠️ 既存プロセスの停止は手動で行う必要がある

## 起動後の確認

どの方法で起動しても、以下のメッセージが表示されれば正常に起動しています：

```
✅ デフォルトデバイスID: [デバイスID]
サーバーが起動しました: http://localhost:3000
SwitchBot APIを使用して電源を制御できます
タイムアウト: 10秒後に自動終了します
```

**注意**: `[デバイスID]`の部分は、`.env`ファイルに`DEVICE_ID`が設定されている場合のみ表示されます。

サーバー起動後、約1秒後に自動でブラウザが `http://localhost:3000` を開きます。

ブラウザが自動で開かない場合は、手動で `http://localhost:3000` にアクセスして、Webアプリが表示されることを確認してください。

## タイムアウト機能

サーバーは起動後、デフォルトで10秒後に自動終了します。環境変数`TIMEOUT_MS`で変更可能です。

例：
```env
TIMEOUT_MS=30000  # 30秒後に自動終了
```

タイムアウト時には、以下の動作が行われます：
1. ブラウザウィンドウが自動で最小化されます（Windows）
2. サーバーが終了します
3. ブラウザタブが自動で閉じられます（可能な場合）

## ブラウザウィンドウの自動最小化（Windows）

Windows環境では、以下のタイミングでブラウザウィンドウが自動で最小化されます：

1. **タイムアウト時**: サーバーが自動終了する際に、現在アクティブなウィンドウを最小化
2. **タブを閉じた後**: ブラウザタブが閉じられた後に、ブラウザウィンドウを最小化

この機能は`minimize_browser_window.ps1`を使用して実装されています。`.exe`ファイルを使用する場合、`minimize_browser_window.ps1`を`dist`フォルダに配置してください。

## トラブルシューティング

### ポートが使用中

**エラー:**
```
❌ エラー: ポート3000は既に使用されています。
```

**解決方法:**
- 既に起動しているサーバーを停止してください
- タスクマネージャーで`node.exe`または`switchbot-app-nexe.exe`を終了
- `.env`ファイルで`PORT=3001`など別のポートを指定

### .envファイルが見つからない

**エラー:**
```
❌ エラー: .envファイルにSWITCHBOT_TOKENとSWITCHBOT_SECRETが設定されていません
```

**解決方法:**
- プロジェクトルート（または`.exe`ファイルと同じディレクトリ）に`.env`ファイルを配置
- `.env`ファイルの内容を確認
- 認証情報の設定方法は [SETUP.md](./SETUP.md) を参照

### 依存関係がインストールされていない

**エラー:**
```
Error: Cannot find module 'express'
```

**解決方法:**
```bash
npm install
```

### 起動方法の選択ガイド

| 状況 | 推奨方法 |
|------|----------|
